# Arquetipo Digital

Landing estática para los servicios de arquitectura de software y consultoría .NET.

## Contenido

- `index.html`: página y estilos.
- `assets/`: imágenes utilizadas por la landing.
- `.agents/skills/landing-page-design/`: skill de diseño instalada para el proyecto.

## Publicar con GitHub Pages

En GitHub, abre **Settings → Pages**. En **Build and deployment**, selecciona **Deploy from a branch**, elige `main` y la carpeta `/ (root)`, y guarda. GitHub Pages publicará el `index.html` del repositorio junto con los recursos de `assets/`.
